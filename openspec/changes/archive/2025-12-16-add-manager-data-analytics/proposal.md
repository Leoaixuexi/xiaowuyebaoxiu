# 变更：重构物业经理数据页面为全局分析视图

## 为什么需要这个变更

物业经理角色（物业经理，role_id 2）目前在标准"数据"页面上的视图功能不完善，无法满足全局监控和数据分析的需求。虽然在单独的管理员页面（`/pages/admin-manager/dashboard`、`/pages/admin-manager/analytics`）中存在分析功能，但主数据页面（`/pages/data/index`）的物业经理视图需要完全重构，以提供：

**重构目标：**
- 实时监控整个物业的所有工单
- 快速识别瓶颈和性能问题
- 基于数据趋势优化资源配置
- 多维度时间过滤（昨天、今天、本周、本月、自定义日期范围）
- 通过Tab切换访问不同视图（数据统计 / 可视化图表）
- 使用ECharts实现专业的数据可视化

**重要说明：**
- 🔄 **这是完全重构**，将删除物业经理（role_id=2）的旧视图代码，替换为全新设计
- ❌ **零破坏性**，物业员工（role_id=4）和维修员（role_id=3）的视图完全不受影响
- ✅ **云开发架构**，使用微信云函数和云数据库，无需传统后端服务器

## 变更内容

- **重构**：完全重构物业经理的数据页面视图，删除旧内容，实现全新的Tab设计

### 核心设计：Tab切换架构

物业经理数据页面将采用Tab切换设计，分为两个主要模块：

**Tab 1: 数据统计**
  - **日期范围选择器**（共享）：
    - 预设时间范围选项：昨天（昨）、今天（今）、本周（周）、本月（月）、自定义日期（日历图标）
    - 时间范围变更时自动刷新数据
    - 实时影响所有统计指标和图表

  - **KPI统计卡片**（2x2网格，4个带动画的卡片）：
    1. **总数卡片**
       - 数值：选定时间范围内的工单总数
    2. **已完成卡片**
       - 数值：已完成工单数量
       - 副标题：完成率百分比
    3. **进行中卡片**
       - 数值：进行中的工单数量
    4. **平均时长卡片**
       - 数值：平均完成时长（小时）
       - 计算方式：从report_time到completed_at的平均时间
    - 卡片动画：淡入 + 上滑效果（使用wx.createAnimation()原生API）
    - 响应式布局：移动端2x2网格显示

  - **排名榜单**：
    - **员工已完成工单排名**：按已完成工单数量排名的员工列表（已提交并完成闭环）
    - **责任方已修复工单排名**：按已修复工单数量排名的责任方列表

**Tab 2: 可视化图表**
  - **服务简报按钮**（右上角）：
    - 一键生成当前数据的PDF/图片简报
    - 支持预览、分享、保存

  - **ECharts可视化图表**（6个图表）：
    1. **工单处理进度环形图**（甜甜圈图）[NEW]
       - 图表类型：环形图（doughnut chart）
       - 内容：各状态工单占比（待维修、维修中、已修复、已完成）
       - 彩色扇区，中心显示总数

    2. **工单趋势折线图**
       - 图表类型：折线图
       - X轴：日期（MM-DD格式）
       - Y轴：工单数量
       - 双线对比：
         - 蓝色线：已提报工单数量
         - 绿色线：已完成工单数量
       - 数据点点击显示提示
       - 可点击图例切换线条显示/隐藏

    3. **故障类型分布饼图**
       - 图表类型：饼图
       - 内容：各故障类型的工单百分比
       - 扇区标签：百分比 + 故障类型名称
       - 悬停提示：显示数量和百分比
       - 图例显示所有故障类型

    4. **责任方分布饼图**
       - 图表类型：饼图
       - 内容：各责任方的工单百分比
       - 扇区标签：百分比 + 责任方名称
       - 点击提示：显示数量和百分比

    5. **楼层分布柱状图**
       - 图表类型：柱状图
       - X轴：楼层名称/编号
       - Y轴：工单数量
       - 柱子点击提示：显示楼层名称和数量
       - 自动排序：按工单数量降序

    6. **位置分布柱状图**
       - 图表类型：柱状图
       - X轴：楼栋/位置名称
       - Y轴：工单数量
       - 悬停提示：显示位置名称和数量
       - 自动排序：按工单数量降序
